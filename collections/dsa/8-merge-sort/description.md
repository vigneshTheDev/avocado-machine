# Merge Sort

Implement `merge_sort(arr)` to sort finite numbers in ascending order. Mutate the supplied array and return void. Support empty and singleton arrays, duplicates, negatives, and fractional values. Divide into halves and merge sorted halves. Use O(n log n) time and O(n) auxiliary storage (plus recursion). Do not delegate to `Array.sort`, `toSorted`, or another sorting library.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `MergeSort`.
