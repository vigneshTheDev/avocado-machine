# Binary Tree Inorder Traversal

Implement `in_order_search(head)` and return node values in left subtree, root, right subtree order. Nodes have `value`, `left`, and `right`; child pointers and the root may be null. An empty tree returns []. Visit every node once in O(n) time, using O(h) auxiliary traversal storage plus the result. Support skewed trees and repeated/negative values. Do not mutate the tree. The tree need not be a BST.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `BTInOrder`.
