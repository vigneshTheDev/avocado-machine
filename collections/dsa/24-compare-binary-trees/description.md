# Compare Binary Trees

Implement `compare(a, b)`, returning true exactly when both binary trees have identical structure and equal values at corresponding nodes. Nodes have `value`, `left`, and `right`; roots and children may be null. Two empty trees are equal; one empty tree is unequal to a nonempty tree. Equal traversed values alone are insufficient if positions differ. Do not mutate either tree. Use O(n) time and O(h) auxiliary traversal space for matching trees.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.
