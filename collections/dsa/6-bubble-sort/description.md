# Bubble Sort

Implement `bubble_sort(arr)` to sort finite numbers in ascending order. Mutate the supplied array and return void. Support empty and singleton arrays, duplicates, negatives, and fractional values. Use adjacent comparisons and swaps. Worst-case O(n²) time and O(1) extra space. Do not delegate to `Array.sort`, `toSorted`, or another sorting library.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.
