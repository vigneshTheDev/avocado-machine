# Binary Search Tree Depth First Search

Implement `dfs(head, needle)`, returning whether a value occurs in a binary search tree. Nodes have `value`, `left`, and `right`; root/children may be null. Values are unique finite numbers; every left subtree value is smaller and every right subtree value larger than its root. Empty input returns false. Follow only the relevant search branch, in O(h) time and at most O(h) auxiliary space, without modifying the tree.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `DFSOnBST`.
