# Stack

Implement a generic LIFO `Stack<T>` with a no-argument constructor. `push(item)` adds to the top, `pop()` removes and returns the newest item, and `peek()` reads the top without removing it. Empty pop/peek return undefined. Public `length` starts at 0 and tracks stored entries. Support draining and refilling, including falsy values. Each operation takes O(1) time (amortized for an array-backed push).

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.
