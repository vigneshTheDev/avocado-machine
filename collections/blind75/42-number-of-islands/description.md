# Number of Islands (Medium)

**Topic:** Graphs · **Difficulty:** Medium

Count connected components of land cells in a grid of "1" and "0".

## TypeScript interface

`numIslands(grid: string[][]): number`

## Example

`grid = [["1", "0"], ["0", "1"]] → 2`

## Rules

Only horizontal and vertical neighbors connect land.

## Constraints

- `1 ≤ rows, cols ≤ 300`
- `grid[i][j]` is `"0"` or `"1"`

Source: [NeetCode problem](https://neetcode.io/problems/count-number-of-islands/)
