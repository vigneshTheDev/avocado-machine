# Binary Search (Membership)

Implement `bs_list(haystack, needle)`, returning a membership boolean (not an index). The input contains finite numbers sorted in nondecreasing order. Empty input returns false; duplicates are valid. Use binary search in O(log n) time and O(1) extra space, without mutating the input or using built-in search helpers.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `BinarySearchList`.
