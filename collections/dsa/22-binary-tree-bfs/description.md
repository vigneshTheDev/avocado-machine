# Binary Tree Breadth First Search

Implement `bfs(head, needle)`, returning whether a node with that value exists. Visit a binary tree breadth first with a FIFO queue; do not assume BST ordering. Nodes have `value`, `left`, and `right`; the root and children may be null. An empty tree returns false. Support repeated and negative values without modifying the tree. Use O(n) time and O(w) queue space, where w is the maximum level width.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `BTBFS`.
