# Quick Sort

Implement `quick_sort(arr)` to sort finite numbers in ascending order. Mutate the supplied array and return void. Support empty and singleton arrays, duplicates, negatives, and fractional values. Partition around a pivot and recursively sort the partitions. Expected O(n log n) time, worst-case O(n²); use in-place partitioning with recursion stack storage. Do not delegate to `Array.sort`, `toSorted`, or another sorting library.

The tests define expected behavior. The algorithm, storage, and complexity requirements above also apply even where behavioral tests cannot enforce them.

Source exercise: `QuickSort`.
